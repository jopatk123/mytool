# 集成测试手册

## 图片工具集成测试

### 测试目标
验证图片工具的扫描、选择和预览功能是否正常工作

### 测试前提
1. 准备一个包含多张图片的测试文件夹
2. 确保图片格式包括: jpg, png, webp 等

### 测试步骤

#### 1. 启动应用
```bash
npm run start
```

#### 2. 导航到图片工具页面
- 从首页点击"图片批量处理"工具卡片

#### 3. 测试文件夹选择功能
- **操作**: 点击"选择文件夹"按钮
- **预期结果**: 
  - 弹出文件选择对话框
  - 选择文件夹后,应用开始扫描
  - 扫描完成后显示找到的图片数量

#### 4. 测试图片列表显示
- **预期结果**:
  - 左侧列表显示所有扫描到的图片
  - 每个列表项包含:
    - 复选框(用于选择)
    - 图片名称
    - 文件大小
    - 相对路径

#### 5. 测试图片预览功能
- **操作**: 应用启动后自动选择第一张图片
- **预期结果**:
  - 第一张图片在列表中高亮显示(蓝色背景+边框)
  - 右侧预览区显示第一张图片的完整信息:
    - 图片预览(可正常加载和显示)
    - 文件名
    - 文件大小
    - 路径
    - MIME类型

#### 6. 测试图片切换功能
- **操作**: 点击列表中的不同图片
- **预期结果**:
  - 被点击的图片在列表中高亮
  - 右侧预览区实时更新为选中图片的信息
  - 图片能正常加载(无"Not allowed to load local resource"错误)

#### 7. 测试复选框功能
- **操作**: 点击列表项的复选框
- **预期结果**:
  - 复选框被勾选
  - 预览图片不会改变(仍然显示当前选中的图片)
  - 顶部统计显示正确的选中数量

#### 8. 测试批量选择功能
- **操作**: 点击"全选"按钮
- **预期结果**: 
  - 所有图片的复选框被勾选
  - 统计显示"当前选中 N / N"

- **操作**: 点击"清除选择"按钮
- **预期结果**:
  - 所有复选框被取消勾选
  - 统计显示"当前选中 0 / N"

#### 9. 测试子文件夹选项
- **操作**: 
  1. 取消勾选"包含子文件夹"
  2. 重新选择同一个文件夹
- **预期结果**:
  - 只扫描顶层文件夹的图片
  - 扫描结果数量减少(如果原本有子文件夹的话)

### 错误检查清单

- [ ] 图片能正常加载,无浏览器控制台错误
- [ ] 点击图片后预览区能正确更新
- [ ] 复选框状态与选中计数一致
- [ ] 大图片预览不会导致UI卡顿
- [ ] 所有按钮功能正常
